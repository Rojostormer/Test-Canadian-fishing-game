# 🎣 Lake Erie Trophy Angler A retro, arcade-style 3D fishing simulator inspired by early-2000s classics like **Rapala Pro Fishing** and **Bass Masters**. Built as a lightweight, single-file HTML5 web application with zero external dependencies. --- ## 🌟 Key Features * **First-Person Boat Navigation:** Move across Lake Erie in a 3D cockpit perspective using responsive throttle and steering controls. * **Lake Erie Topographical GPS:** Real-time minimap rendering depth contours based on authentic Lake Erie structures, including shallow western basins and offshore shoals. * **Digital Sonar / Fish Finder:** Live scrolling LCD sonar unit tracking bottom topography and marking nearby fish arches in real-time. * **Underwater Reeling Battles:** Once a fish strikes, the camera cuts below the water surface into an active fight phase. * **Rapala-Style Tension Physics:** * Counter-steer your rod (`A`/`D`) against the fish's swimming direction. * Manage line tension (`W` to reel, `S` to give slack) to prevent line snaps during surges. * **Tackle & Equipment Mechanics:** Select from various lures (Shad Raps, Skitter Walks, DT-10s) and baits (Emerald Shiners, Nightcrawlers) that directly impact fish attraction rates and target species. --- ## 🕹️ Controls | Action | Keyboard | On-Screen Buttons | | :--- | :--- | :--- | | **Move Forward / Reel Line** | `W` or `Up Arrow` | `▲ FWD / REEL` | | **Reverse / Give Line Slack** | `S` or `Down Arrow` | `▼ REV / SLACK` | | **Steer Left / Angle Rod Left** | `A` or `Left Arrow` | `◀ STEER / ROD L` | | **Steer Right / Angle Rod Right** | `D` or `Right Arrow` | `STEER / ROD R ▶` | | **Cast / Hook / Main Action** | `Spacebar` / Click | `CAST LINE` / `SET HOOK` | --- ## 🐟 Target Species & Tackle Strategy | Lure Type | Target Depth | Effective Species | | :--- | :--- | :--- | | **Skitter Walk** | Shallow (0 - 4 ft) | Topwater strikes | | **Husky Jerk** | Mid-depth (4 - 10 ft) | Smallmouth Bass, Yellow Perch | | **Shad Rap** | Deep (8 - 15 ft) | Walleye, Bass | | **DT-10** | Structure Deep (10 - 25 ft) | Deep Lake Trout, Monster Walleye | --- ## 🚀 Quick Start / Installation No build steps or package managers required. 1. Clone or download the repository. 2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari). 3. Click **CAST LINE** to begin your tournament!
