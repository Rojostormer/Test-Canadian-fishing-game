# Canadian Waters — Safari Prototype

Open `index.html` in a web browser. For iPhone testing, upload this folder to any static web host and open its HTTPS address in Safari.

Gameplay:
1. Choose a lure.
2. Tap CAST.
3. Wait for the strike.
4. Tap SET THE HOOK.
5. During the fight, alternate REEL IN and LET IT RUN.
6. Land the fish and build your Trophy Book.

The prototype is intentionally self-contained: no server, account, or external libraries are required.
