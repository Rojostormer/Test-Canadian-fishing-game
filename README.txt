# Canadian Waters — First-Person Pro Fishing

Open `index.html` in any web browser. For mobile testing, host on a local web server or static host and load the HTTPS URL in Safari.

## What's New in This Version:
1. **First-Person Cockpit View:** Replaced the top-down perspective with an immersive 3D first-person perspective complete with a dynamic water horizon, tree silhouettes raycasted along the shore, a visible boat deck, and a fishing rod tip.
2. **Fixed Casting Constraints:** You can no longer cast off-screen or out of bounds. Clicks and drags are clamped safely within drivable water boundaries.
3. **Retrieval Controls:** Added a dedicated "REEL IN" line retrieve button during casting and waiting phases so you can cancel or abort casts instantly.
4. **Zoom Controls:** Added zoom (+ / −) buttons on top right of screen to dynamically scale the camera's FOV and casting reach.
5. **Dual Live Dashboard Displays:**
   - **Fish Finder (Sonar):** Real-time bottom contour sonar unit that tracks depth and generates fish arch blips when driving over fishing hotspots.
   - **Overview Map:** Real-time mini-map showing the lake shoreline, active hotspots, and live boat location/heading orientation.
